# DT4FM — Digital Twin para la Gestión de Instalaciones

DT4FM es una plataforma diseñada para gestionar las operaciones de instalaciones utilizando un enfoque de gemelo digital (Digital Twin).

El sistema integra flujos de trabajo operativos, gestión de activos y reporte de incidentes dentro de una arquitectura escalable.

## Arquitectura

Frontend  
React + Vite

Backend  
NestJS

Base de datos  
PostgreSQL
